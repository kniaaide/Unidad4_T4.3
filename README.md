# Unidad4_T4.3 — Dijkstra y logística

Proyecto académico en C# sobre **grafos y búsqueda de rutas** en un contexto de logística.

## Contenido

La solución organiza el código en las carpetas `Grafos`, `Algoritmos` y `Modelo`, además de incluir una interfaz Windows Forms (`MainForm.cs`). El proyecto se centra en el algoritmo de Dijkstra.

## Requisitos

- Visual Studio con soporte para C# y Windows Forms.
- .NET compatible con `Unidad4_T4.3.csproj`.

## Ejecución

Abre `Unidad4_T4.3.sln` en Visual Studio y ejecuta el proyecto.

## Propósito

Representar grafos y aplicar Dijkstra para explorar rutas de costo mínimo.
